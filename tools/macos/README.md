# Werkzeuge für macOS

Zum Spielen öffnest du `Starten.command` im Hauptordner.
Dieser gemeinsame Start nutzt die gespeicherten Einstellungen.
Die Sprachkalibrierung bleibt nach einem Neustart erhalten.

Diese Dateien erfüllen andere Aufgaben:

| Datei | Aufgabe |
| --- | --- |
| `Sprache einrichten.command` | Richtet die lokale Spracherkennung einmalig auf einem neuen Mac ein. |
| `Mikrofon testen.command` | Öffnet die Sprachübung und erstellt einen Bericht mit Messwerten. |
| `Strecken prüfen.command` | Prüft die Streckendateien. |
| `Bauteile ansehen.command` | Öffnet die Bauteile im Godot-Editor. |
| `Qualitätsprobe starten.command` | Öffnet die alte, getrennte Grafikprobe. |

Der Mikrofontest führt die Kalibrierung gezielt erneut aus.
Für eine normale Fahrt brauchst du diesen Test nicht.
Die Einrichtung und die getrennten Vorschauen starten nicht das aktuelle Spiel.
